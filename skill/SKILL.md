# 麦麦食历 · 选餐魔盒

## 什么时候用

用户表达"不知道吃什么""帮我选一个""随便来点""今天想吃点……"这类**单次选餐**诉求时使用。
不适用于：一周饮食规划、营养/减脂方案、点餐下单与支付。

## 交互原则

1. **先给选择，再问细节**。用户可以不回答任何问题，直接开盒。
2. **不问三次以上**。每次只问一句，或者干脆不问。
3. **不复述隐私**。不打听病史、体重、收入；预算只说上限。
4. **不做心理分析、不给营养结论**。理由只能引用"用户说的话 / 接口数据 / 规则本身"。

## 工作流

### 第一步：收输入（可跳过任意项）

按需问，一次最多问一句：

- 今天怎么样：`累了` / `心情不错` / `有点低落` / `想奖励自己` / `就想简单解决`
- 想吃点什么感觉的：`满足` / `热乎` / `清爽` / `甜一点` / `想尝鲜`（最多两个）
- 有多饿：`垫一下` / `正常` / `很饿`
- 预算上限（**不要替用户假设，没说不设**）
- 不吃什么：`牛肉` / `辣` / `冰` / `咖啡` / `猪肉` / `鱼`

用户直接说了一句话时，走文本入口，**先把解析结果回显给用户确认**，再开盒。

### 第二步：开盒

```bash
python -m mcd_box.cli --state 累了 --feel 满足 --budget 30
python -m mcd_box.cli --text "今天汇报搞砸了，想吃点满足的，别超过35元"
python -m mcd_box.cli --random
python -m mcd_box.cli --state 想奖励自己 --budget 40 --offline   # 无网/无 Token
```

需要结构化结果时加 `--json`。

### 第三步：展示三张卡

必须是三个角色，不能合并成一个：**懂你款 / 稳妥款 / 惊喜款**。
每张卡至少包含：餐品名、价格、一句理由、数据来源与时间。
用户说"再来一盒"就重新跑（seed 自动变）；说"就这个"就结束，不要追问要不要下单。

### 第四步：收尾

- 用户要下单 → 引导到麦当劳官方 App/小程序，**不要代下单**。
- 用户问营养 → 说明营养数据不完整，不提供热量/蛋白结论。
- 用户问过敏 → 说明只能按名称匹配，请向门店核实成分。

## 边界

- 不做医疗或营养建议，不提供疾病饮食方案。
- 不承诺"绝对安全""无过敏原"。
- 不声称能读取用户在其他应用中的搜索或浏览记录。
- 价格与供应以门店实际为准；卡片必须带抓取时间。
